# nie: agent contract

nie is the self-hosted Inazuma Eleven engine and studio, and the home of all Rose Griffon Rust. It
loads game data from the installation the user owns and keeps a football craft layer. See
`README.md` for the layout.

## Rules

- Rust 2024 workspace, one copy per crate. The Bevy family is the `vendor/bevy` fork (`=0.20.0-dev`)
  and Dioxus the `vendor/dioxus` fork, both git submodules with relative URLs wired through
  `[patch.crates-io]`. Other dependency versions are read live from crates.io
  (`curl -A nie https://crates.io/api/v1/crates/<name>`). A third-party Bevy crate needs its own fork
  under `vendor/` first, because crates.io releases require `bevy ^0.20` and cannot resolve against a
  prerelease. Never edit a fork from here; fix it upstream in its repository and let `vendor-sync` bump.
- Never ship, copy or commit a game asset. Game data is read in place through `nie-assets`
  (`game://`) from a local path, SSH, or an rclone remote. Tests build synthetic fixtures in a temp
  directory.
- Football content is original: no names, characters, art, music or levels from a commercial game.
- `nie-sim` stays deterministic: integer RNG, `+ - * /` and `sqrt` only, stable entity order, no
  wall-clock time. A change that moves the pinned score or checksum in
  `crates/nie-sim/tests/headless.rs` is a gameplay change and must say so.
- New football behavior goes into engine crates and is selected through the manifest.
- `contract/nie-app.json` and `contract/aphrody-store.toml` are generated by `nie-shell`; the test
  in `crates/nie-shell` fails when they drift.
- Heavy builds run on the build host (`ssh fr1`, `/srv/xbuild/nie`) or in CI. Commit by path on
  `main`, no AI attribution, check `gh run list -R aphrody-labs/nie` after pushing.
- Claude Code setup is generated: edit `tools/claude/profile.toml` (MCP servers, plugins, skills
  kept for nie) and run `bun ~/.claude/scripts/profile.ts` (the engine of aphrody-labs/claude, also
  re-applied at SessionStart); `--check` reports drift. `.mcp.json` starts the
  native `nie-mcp` server (local build, else the build host over SSH). Never hand-edit
  `.claude/settings.json`.
- nie is a standalone deployed service; consumers such as rosegriffon call it over HTTP and never
  embed its Rust.
- English, no emoji.
