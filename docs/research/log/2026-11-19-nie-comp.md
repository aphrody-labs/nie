# 2026-11-19: nie-comp, the session compositor on smithay 0.7.0

## Question

Can the nie desktop shell (GPUI panels over wlr-layer-shell, plan section 13 step 5) get a session
compositor from crates.io only, that runs with no GPU, no DRM and no display on the build host so
CI can composite real client surfaces and write a screenshot?

## Method

1. smithay 0.7.0 exposes `smithay::wayland::shell::wlr_layer` (`WlrLayerShellState`,
   `WlrLayerShellHandler`, with `smithay::desktop::layer_map_for_output` for exclusive zones): the
   protocol GPUI's `gpui_linux/layer_shell.rs` binds.
2. Headless backend evaluation, read in the 0.7.0 sources:
   - `backend::renderer::test::DummyRenderer` imports buffers and draws nothing (its frame methods are
     empty), so it cannot produce pixels. Rejected.
   - `backend::renderer::pixman::PixmanRenderer` (feature `renderer_pixman`, CPU): implements
     `Offscreen<pixman::Image>`, `Bind<pixman::Image>`, `ExportMem`, `ImportMemWl`, `ImportDma`.
     Chosen: render into an offscreen `Abgr8888` image, read it back with `copy_framebuffer`.
3. One scene, one render path generic over the renderer (`render_scene`): `desktop::space::render_output`
   with layer surfaces from the output's `LayerMap`; every xdg toplevel is configured to the zone the
   layers leave free. The same code is driven by PixmanRenderer (headless), GlesRenderer (winit) and
   `DrmCompositor` (drm).
4. Protocols: xdg-shell, wlr-layer-shell, wl_seat (keyboard, pointer), wl_shm, linux-dmabuf (formats of
   the renderer), wl_output with xdg-output, wl_data_device_manager, presentation-time (frame callbacks
   and feedback after every frame), viewporter, xdg-decoration (always client side). XWayland is the
   `xwayland` feature (spawns `Xwayland`, X11 windows join the same scene), off by default.
5. Features: `winit` (nested window, GLES), `drm` (libseat session, udev primary GPU, gbm, libinput,
   `DrmCompositor`), `xwayland`. Linux only: dependencies are under
   `[target.'cfg(target_os = "linux")']` and the library has `#![cfg(target_os = "linux")]`.
