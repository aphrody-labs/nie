# 2026-11-19: duplicated logic across crates/ and plugins/

## Question

Which functions and types are copied between crates, and which copies can be fused into the
lowest crate that already depends on every user, without a new dependency edge that breaks
`docs/specs/framework-layering.json`?

## Environment

- Build host fr1, private copy `/srv/xbuild/nie-dedupe` (tracked and untracked files of the PC tree
  at the time, `vendor/` excluded), `CARGO_TARGET_DIR=/srv/xbuild/nie-dedupe/target`.
- Clone detector: `bunx jscpd` (rust, `--min-tokens 60 --min-lines 8`, ignoring `target`,
  `abi_generated.rs`, `tests`) on `crates plugins apps`: 787 files, 339831 lines, 305 clones,
  4090 duplicated lines (1.20 percent). Same-name sweep: `rg '^\s*(pub )?fn <name>'` over every
  `fn` name that occurs three times or more.
- Line numbers below are those of the scanned tree before the fusions.
